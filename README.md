## 🚀 Featured Projects

### 1. [Figgo Atlas — Distributed Browser Automation Platform](https://github.com/abdulrehmanmazhar/trip-2-go-scraper)

A multi-component automation platform designed to coordinate browser-based data collection, network inspection, workflow tooling, and remote execution.

**Engineering highlights**

- **Network recording:** Browser automation and network-inspection tooling built around Playwright.
- **Dump analysis:** Separate backend and client components for working with captured data.
- **Workflow tooling:** A dedicated workflow-recorder structure with frontend, backend, and CLI components.
- **Automation workers:** A bot component designed to support browser-driven automation.
- **Real-time communication:** A shared WebSocket RPC package for communication between system components.
- **Backend services:** Express, MongoDB/Mongoose, logging, file handling, and storage integrations.
- **Deployment architecture:** Docker Compose, Nginx, MongoDB, MinIO, and Cloudflare Tunnel-related infrastructure.

**Technology stack**

`TypeScript` · `Node.js` · `React` · `Vite` · `Express` · `MongoDB` · `Mongoose` · `Playwright` · `WebSockets` · `MinIO` · `Docker` · `Nginx`

**What it demonstrates:** Multi-package application architecture, browser automation, service integration, and the engineering challenges involved in coordinating automation across multiple components.

**Repository:** [trip-2-go-scraper](https://github.com/abdulrehmanmazhar/trip-2-go-scraper)
